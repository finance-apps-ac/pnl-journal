# P&L — Trading Journal

A clean, private trading journal. Log trades and realized P&L, track holdings and
unrealized gains, watch your equity curve and monthly stats, and see portfolio
contributions on a dial. Multi-year. Light & dark theme (follows your system, with a
toggle). CSV import/export.

**Everything stays on your device.** Data is saved in your browser's local storage and
is never uploaded — there is no account and no server.

## Live demo
Open `demo.html` to see the app pre-filled with example trades, holdings, and stats —
a quick way to preview how it looks once you've been using it. The demo uses sample data
held in memory only; it never saves anything and never touches your real journal.

## Run it
Just open `index.html` in any modern browser, or host the folder as a static site
(GitHub Pages, Netlify, etc.). It's a single self-contained HTML file — no build step.

## Install as an app
On iPhone/iPad or Android: open the hosted page, then **Share → Add to Home Screen**.
It launches full-screen with its own icon (PWA).

## Files
- `index.html` — the whole app
- `manifest.webmanifest`, `icon-*.png`, `icon.svg` — installable-app metadata + icons

## Note
This is a personal journaling tool, **not financial advice**. It records what you enter;
it does not recommend trades.
